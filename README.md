# Lempikirjat
*  Käyttäjä pystyy luomaan tunnuksen ja kirjautumaan sisään sovellukseen.
*  Käyttäjä pystyy lisäämään sovellukseen lukemiaan kirjoja, sekä arvostelut niistä. Lisäksi käyttäjä pystyy muokkaamaan ja poistamaan lisäämiään kirjoja.
*  Käyttäjä näkee sovellukseen lisätyt arvostelut. Käyttäjä näkee sekä itse lisäämänsä että muiden käyttäjien lukemat kirja-arvostelut.
*  Käyttäjä pystyy etsimään kirjoja hakusanalla tai muulla perusteella. Käyttäjä pystyy hakemaan sekä itse lisäämiään että muiden käyttäjien lukemia kirjoja. Käyttäjä pystyy myös lisätä muiden lukemia kirjoja omalle lukulistalleen.
*  Sovelluksessa on käyttäjäsivut, jotka näyttävät jokaisesta käyttäjästä tilastoja ja käyttäjän lukemat kirjat.
*  Kirjoille on valittavissa useampia luokitteluja. Valittavissa olevat luokittelut tulee määritellä tietokannassa. Käyttäjä voi valita jokaisen luokittelun kohdalla yhden tai useamman vaihtoehdon. (esim. kirjan genre, kirjan arvosana 1-10 asteikolla)
*  Sovelluksessa on pääasiallisen lukemien kirjojen lisäksi toissijainen tietokohde, joka täydentää pääasiallista tietokohdetta. Käyttäjä pystyy lisäämään kommentteja omiin ja muiden käyttäjien kirja-arvioihin liittyen.
